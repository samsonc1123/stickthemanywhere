# Agent Operating Manual: StickerCanvas

## 1. Runtime & Package Manager: Bun-First
- **Primary:** Bun is the default runtime and package manager.
- **Fallback:** Use Node/npm only if explicitly required by a dependency, and document the exception in the PR or agent output.
- **Commands:** Use `bun install`, `bun run <script>`, and `bunx <binary>`.

## 2. Backend: Convex Transition
- **Source of Truth:** All new schema, queries, mutations, and business logic must be implemented in Convex (`convex/`).
- **Legacy Path:** The Express server (`server/index.ts`) is in **Maintenance Mode**. Do not add new routes or core business logic there unless required for a critical fix to existing legacy infrastructure.
- **Storage:** Supabase is **Legacy/Transition Storage**. Do not build new file workflows around Supabase unless the existing repo still requires it and the exception is documented.

## 3. Taxonomy & Code Generation
- **Direction:** Taxonomy is backend-driven. Never derive category, subcategory, or group from filenames.
- **Canonical Format:** Sticker codes are generated as:
  `<subcategoryCode><5-digit-sequence>`
  Example: `POK-TYP00001`
- **Normalization:** Use `normalizeTaxonomyCode` from the shared library where applicable.
- **Frontend Rule:** Frontend must never hardcode taxonomy data. All taxonomy must be fetched from Convex at runtime.

## 4. Agent Execution Rules
- **Fix the Root:** Prefer system-level fixes over manual workarounds.
- **Pivot Protocol:** If a fix fails twice at the same layer, pivot immediately to a different layer.
- **No Duct Tape Canonization:** Emergency workarounds (such as shims or node_modules patching) must be labeled `[TEMP]` and followed by a proper architectural fix.
- **Deliverables:** Every code-changing response must include:
  1. Relative file paths changed
  2. Full copy-paste code
  3. Exact commands to run

## 5. Runbook (Ground Truth)
- **Full Stack Dev:** `bun run dev`
- **Convex Watch:** `bunx convex dev` (run from Replit Shell)
- **Production Deploy:** `bunx convex deploy`
