### Task 3: Refactor Taxonomy Schema & Mutations (Infinite Scale)
Our current taxonomy structure is flat or inverted. We need a robust, scalable **Tertiary Taxonomy System** that allows us to scale stickers infinitely without subcategories getting orphaned or overlapping.

#### 1. Update the Convex Schema (`convex/schema.ts`)
Define a clear, relational hierarchy where Subcategories explicitly belong to Categories, and Stickers explicitly reference their Subcategory.

```typescript
import { defineSchema, defineTable } from "convex/server";
import { v } from "convex/values";

export default defineSchema({
  // 1. Root Categories (e.g., Animals, Flowers, Gaming)
  categories: defineTable({
    name: v.string(),            // Unique display name
    slug: v.string(),            // For clean URL routing
  }).index("by_slug", ["slug"]),

  // 2. Subcategories (Explicitly linked to a parent Category)
  subcategories: defineTable({
    categoryId: v.id("categories"), // The parent relational link
    name: v.string(),               // e.g., "Dogs" under "Animals"
    prefix: v.string(),             // Code prefix used for generating sequential sticker codes
  })
  .index("by_category", ["categoryId"])
  .index("by_prefix", ["prefix"]),

  // 3. Stickers (Scale infinitely by pointing directly to their Subcategory)
  stickers: defineTable({
    subcategoryId: v.id("subcategories"), 
    imageUrl: v.string(),
    stickerCode: v.string(), // e.g., "DOG-001" generated sequentially based on subcategory prefix
    createdAt: v.number(),
  }).index("by_subcategory", ["subcategoryId"]),
});
