StickThemAnywhere: Automated Fabrication Control Plane
System Overview
This repository contains the R&D and logic for a modular, multi-tier digital asset control plane. The system is engineered to ingest, sort, and manage high-fidelity design assets for automated fabrication workflows.
Key Architectural Features
 Convex Backend Integration: Utilizes Convex for state management and real-time synchronization of asset data across the fabrication pipeline.
 Tertiary Layering System: A scalable architecture for categorical asset management and hierarchical sorting.
 Automated Ingestion Logic: Built-in pipelines for asset upload, diagnostic review, and categorical routing.
 Dynamic Interactivity: Integrated triggers for visual asset feedback, demonstrating modular UI/UX control.
